# Nexo · Mesa de soporte

Aplicación de soporte interno con tres funcionalidades: registrar, consultar y atender tickets.


## Funcionalidades

- **Registrar:** asunto, solicitante, correo, área, categoría, prioridad, personas afectadas y descripción.
- **Consultar:** listado, búsqueda, filtros, tablero y detalle.
- **Atender:** técnico, persona atendida, diagnóstico, revisión, solución e historial.



## Estructura

- `ManteniWeb.sln`: solución de Visual Studio.
- `ManteniWeb/Default.aspx`: interfaz.
- `ManteniWeb/Default.aspx.cs`: métodos Ajax y acceso a Session.
- `ManteniWeb/Models/`: modelos.
- `ManteniWeb/Services/`: validaciones y lógica de atención.
- `ManteniWeb/Scripts/`: JavaScript y jQuery.
- `ManteniWeb/Content/`: estilos.
- `INICIAR.ps1`: inicio local alternativo.
